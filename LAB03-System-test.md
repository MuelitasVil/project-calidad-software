| ID    | Requerimiento                                                                                 |
|-------|------------------------------------------------------------------------------------------------|
| FR-01 | El sistema debe proporcionar una página de inicio de sesión con un campo para Correo y Contraseña. |
| FR-02 | Cuando se proporcionen credenciales válidas, el sistema debe autenticar al usuario.            |
| FR-03 | Tras la autenticación, el sistema debe redirigir al usuario al Tablero (Dashboard).            |
| FR-04 | Si las credenciales no son válidas, el sistema debe mostrar un mensaje de error sin redirigir. |
